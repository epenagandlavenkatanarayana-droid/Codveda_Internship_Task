# Level 2 – Java Tasks

This folder contains the Level 2 tasks completed as part of the Codveda Technologies Java Development Internship.  
Level 2 focuses on writing slightly more structured Java programs with better logic and flow.

---

## Task Overview

The tasks in this level are designed to move beyond basics and apply Java concepts in practical scenarios.  
All programs are console based and organized for easy execution.

---

## Topics Covered

- Methods and functions  
- Classes and objects  
- Menu driven programs  
- Logical problem solving  
- Basic validation and control flow  

---

## How to Run

1. Open the project in a Java IDE  
2. Go to the Level 2 folder  
3. Execute the main class file  

---

## Objective

The goal of Level 2 is to improve problem solving skills and understand how to structure Java programs properly.
