# Level 3 – Java Tasks

This folder contains the Level 3 tasks completed during the Codveda Technologies Java Development Internship.

## Task Overview

- Multiple classes interaction  
- Exception handling  
- User driven program flow  
- Cleaner and modular code structure

2. Navigate to the Level 3 folder  
3. Run the main class

The purpose of Level 3 is to strengthen understanding of OOP concepts and improve code organization.
